# Cai De Vera — Visual Identity & Graphic Design Studio

Portfolio and interactive design laboratory of **Cai De Vera**, Senior Graphic Designer & Art Director specializing in brand identity systems, kinetic typography, structural packaging, and Swiss editorial monographs.

---

## 🌟 Key Features

- **Iconic Brand Systems & Case Studies**: In-depth design breakdowns with interactive Before/After sliders, typographic specimen inspectors, color token copy utilities, and production galleries.
- **Interactive Poster & Type Lab**: Live sandbox with Swiss grid overlays, noise grain filters, variable type treatments, palette swatches, and high-res PNG poster export.
- **Brand Architecture & Vector Anatomy**: Live SVG construction grid with optical proportion guides, bezier curves, and production tokens (WCAG AAA, PMS spot colors, vector formats).
- **Scope & Cost Calculator**: Transparent estimation tool with real-time budget forecasting, timeline sprint multipliers, and seamless brief export to the commission inquiry form.
- **Spotlight Command Palette (`⌘K` / `Ctrl+K`)**: Instant keyboard navigation to jump to case studies, tool labs, theme modes, and CV modals.
- **Multi-Theme Engine**: Seamless switching between **Obsidian Dark**, **Modernist Light**, and **Acid Cyber** aesthetic themes.
- **Synthesized Tactile Audio**: Real-time Web Audio API micro-haptics for clicks, pops, hovers, and celebratory confetti dispatches.
- **Printable Curriculum Vitae & Press Kit**: High-density typography-first resume with print-ready stylesheet formatting.
